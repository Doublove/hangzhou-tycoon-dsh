# 杭州大富翁 · Hangzhou Tycoon

以 2010—2026 年杭州楼市为背景的回合制地产经营游戏。一回合一个月，四章十六年，买地、加杠杆、扛调控。

**在线试玩：** https://doublove.github.io/hangzhou-tycoon-dsh/
**仓库：** https://github.com/Doublove/hangzhou-tycoon-dsh
**当前版本：** v2.0.0 ｜ 变更记录见 [CHANGELOG.md](./CHANGELOG.md) ｜ 需求文档见 [`docs/杭州大富翁_游戏开发需求文档_V1.9.docx`](./docs/)

## 已实现的需求

### 一、结构与时间

| 需求 | 实现 |
|------|------|
| 一回合 = 一个月 | `endMonth()`：存活玩家各行动一次后推进 |
| 四章 204 回合 | 48 / 48 / 48 / 60，对应 2010—2026 |
| 棋盘 | 每章一个 **7×7 方环**，24 格 = 起点 1 + 地块 16 + 功能格 7；监狱在棋盘中心，只能被卡牌送进去 |
| 章节继承 | 净资产 × 40% 折算，保留 1 宗最贵地块作为「时代遗产」 |
| 中途开局 | 任选一章直接开局，系统自动补演此前的历史事件与政策 |
| 破产不复活 | 出局者在后续章节保持出局 |

### 二、掷骰与移动

| 需求 | 实现 |
|------|------|
| 单骰 1—6 | 一圈 26 格约 7.4 回合走完 |
| 经过起点 | **月供 1 万 + 当前现金 3%**（原固定 150 万）；**正反向都结算** |
| 监狱 | 踩中或被卡送进来，掷出偶数（2/4/6）出狱；连续 3 次未中，第 4 回合强制释放 |
| 风景区 | 第一章西湖风景区 / 第二章运河夜游 / 第三章亚运场馆 / 第四章良渚遗址；停留回合按梯度抽取（见下表） |

**风景区停留梯度：** 1 回合 50% ｜ 2 回合 25% ｜ 3 回合 12% ｜ 4 回合 7% ｜ 5 回合 5% ｜ 6 回合 1%（期望 1.95 回合）。阿莲的被动使停留减半。

### 三、地块与过路费

| 需求 | 实现 |
|------|------|
| 12 个区域 / 64 宗地块 | 每环 16 宗，按历史节点陆续挂牌 |
| 功能格构成 | 机会 3/21、命运 6、证券 12、道具店 15、银行 18、风景区 9；监狱在中心 |
| 道具商店 | 落在 15 号格，按「净资产 × 3%（下限 10 万）」买四种道具 |
| 卡池抽样 | 机会 25 / 命运 26 张全在 config.js；每局只抽 25 张，抽完洗牌 |
| 地块等级 | Lv0—Lv5，租金率逐级 0.8% / 1.1% / 1.4% / 1.7% / 2.0% |
| 过路费费率 | Lv1 **10%**，逐级 12% / 14% / 16% / 18% |
| 连片加成 | 环上相邻地块同主，过路费 **×2**；三连不叠乘，跨起点不算相邻 |
| 连片特效 | 同主相邻地块显示 `×2` 标签、底色与环内侧同色连接带 |
| 单次上限 | 不超过支付方净资产的 **30%**，超出部分「经调解减免」 |
| 杠杆豁免 | 杠杆率（负债 ÷ 净资产）**> 50%** 时不再享有上限，全额支付 |
| 物业费 | 每月按地价 **0.15%**，空地减半（0.075%） |
| 摇号 | 2018.04 起，热度 ≥ 60 的板块买地需抽签，中签率 0.85 − 热度/150 |
| 限价 | 2021.08 起卖地收益封顶 |
| 烂尾 | 2022.05 起，城东 / 城北 / 临平 / 三江汇的在建地块可能停工归零 |

### 四、经济与破产

| 需求 | 实现 |
|------|------|
| 银行贷款 | 月息 0.6%，额度 = 净资产 × 60%；限贷期 40% 且加息至 0.75% |
| 单次借款 | ≤ 200 万 |
| 净资产 | 现金 + Σ 地价 ×(1 + 12%×等级) + 股票 − 负债 |
| 现金为负 | 按价值从低到高强制卖地（8 折），卖完仍为负则出局 |
| **两级破产** | 净资产 < 0 → 强制拍卖（85% 卖给玩家 / 70% 抵押银行）→ **3 个月**宽限 → 仍未还清则出局 |
| 股票 | 证券交易所买卖「杭州楼市指数」 |

## 视觉系统

界面走「技术面板」路线：深灰底、锐角、细线、等宽数字、单一强调色（红）。
八个区块各换一种材质，底部统一收在一条 4px 深的「磁吸托架」上，四角带螺钉。

| 区块 | 材质 | 做法 |
|---|---|---|
| 玩家栏 | 档案袋 | 卷宗标签页 + 回形针 + 档案行 |
| 楼市指数 | 炒股终端 | 纯黑底、窗栏三点、网格背景、等宽数字 |
| 道具 / 技能 | 手机 | 机身圆角、听筒条、Home 指示条 |
| 掷骰 | 聚宝盆 | 金铜渐变 + 盆口高光 + 盆底阴影 |
| 菜单 | 字典 | 书脊皮革渐变 + 侧边字母 + 竖排文字 |
| 日志 | 账单 | 米色小票、齿孔、等宽字、「消费明细」页脚 |
| 棋盘 | 围棋盘 | 木纹盘面 + 24 等分棋格 + 五个星位，棋子即围棋子 |
| 页面底 | 卫星影像 | 杭州城区卫星图压暗后固定，叠一层扫描线 |

**地块建筑**是矢量立面，五级五个体量：Lv1 单间平房（坡屋顶）、Lv2 两层平房（女儿墙）、
Lv3 公寓楼（五层阳台 + 水箱）、Lv4 写字楼（幕墙竖挺 + 收分塔身）、Lv5 商业综合体（裙房 + 塔楼 + 灯带）。
统一 24×32 画布、同一基线、同一投影，配色随所属区域派生——**看轮廓就能判断等级**，门头一律无字（合规要求）。

**棋盘底纹**是本章结束年份的地铁线网：2013 两条、2017 四条、2021 七条、2026 九条。
画的是拓扑示意（只有线段、折点、站点圆点），不画行政边界、不标经纬度。

素材全部在 `art.js`（生成 SVG）与 `art.css`（材质与布局）里，除页面底图外没有位图依赖；
> 页面底图 `assets/hangzhou-satellite.png` 为公开渠道获取的卫星影像，**对外发布前需确认授权**；
> 建筑与线网均为本项目自制矢量图，不含任何真实项目外观或地图注记。


`assets/art-preview.html` 是一页看得全的美术板。

## 怎么玩

点「开始游戏」，选角色、难度、起始章节。默认杭铁头 + 算账型 + 第一章，一局约 25 分钟。

**几条能立刻用上的经验：**

- **连片是核心。** 相邻地块同主，过路费翻倍。买地时先看左右两格是谁的。
- **停留卡要看脚下。** 在自家地上用＝再升一级；在对手地上用＝再付一次过路费。
- **别把杠杆拉过 50%。** 越线之后，踩到对手的地不再有 30% 净资产封顶，一次可能付掉大半身家。
- **现金要留够。** 一次落地约等于 10 倍月租，现金见底就只能 8 折卖地，割肉比付过路费更疼。
- **限购会真的卡住你。** 2011.02 起名下满 2 套就买不了地，持续 12 个月。
- **摇号看热度。** 2018.04 之后，热度 90 的板块中签率只有 25%。

## 关键数值（调参入口）

全部集中在 **`config.js`**，参数名与代码变量名一一对应：

| 参数 | 位置 | 当前值 |
|---|---|---|
| 章节回合数 | `CFG.chapters` | `[48, 48, 48, 60]` |
| 起点结算 | `CFG.passGo` / `CFG.passGoRate` | 1 万 + 现金 3% |
| 过路费上限 | `CFG.tollCap` | 净资产 30%（V1.6 目标 25%） |
| 杠杆豁免线 | `CFG.levThreshold` | 50% |
| 物业费 | `CFG.mgmtRate` / `CFG.mgmtVacantRate` | 0.15% / 0.075% |
| 升级费 / 卖地回笼 | `CFG.upRate` / `CFG.sellRate` | 60% / 80% |
| 贷款利率 | `CFG.loanRate` / `CFG.loanRateTight` | 0.6% / 0.75% |
| 贷款额度 | `CFG.loanCap` / `CFG.loanCapTight` | 60% / 40% |
| 税务 | `CFG.taxRate` | 净资产 × 1.2% |
| 景区停留概率 | `CFG.scenicOdds` | `[50,25,12,7,5,1]` |
| 清算宽限 | `CFG.liqMonths` | 3 个月 |
| 初始道具 / 掉率 | `CFG.items` | 骰 3 / 停 1 / 掉头 1 / 路障 1；机会 35% |
| 时代系数 | `ERA` | 2010=1.00 … 2021=2.10 … 2026=1.60 |
| 租金率 | `RENT_RATE` | `[0,.008,.011,.014,.017,.020]` |
| 过路费率 | `TOLL_RATE` | `[0,.10,.12,.14,.16,.18]` |
| 升级门槛 | `UP_GATE` | 热度 30/45/60/75 + 持有回合 |

改完刷新页面即生效；不需要重新构建，也不需要改 `data.js` / `game.js`。
`config.js` 用 `.js` 而非 `.json`，是因为 `file://` 下 `fetch('config.json')` 会被同源策略拦掉，
而本站承诺双击 `index.html` 即可离线游玩。

## 自动化测试

232 条用例覆盖地图、经济、回合、事件卡牌、道具、技能、破产、存档、悬浮说明与整局不变量。测试直接加载 `data.js` / `game.js` 本体，不维护第二份逻辑。

```bash
npm test            # 全部用例，约 16 秒
npm run test:unit   # 只跑单模块（跳过整局模拟）
npm run test:balance # 只跑整局不变量
npm run test:doc    # 重新生成 tests/测试用例.md
```

## 已知问题

- **破产率约 4%**（1/24 人次，204 回合战役）。地可以 8 折变现，只要名下有地，任何一次打击都能化解——真正致命的是「没钱 + 没地」同时发生。
- **热度自然回归未实现**（`TC-ECO-37`）：热度只能被事件单向推动，长期会顶在上下限，板块轮动体感偏弱。
- **贷款利率对所有角色都打了 8 折**（`TC-ECO-35`）：`loanRate()` 统一 ×0.8，实际 0.48%/月，温老板「利息 −20%」的被动被错误地施加给了所有人。
- **税务格不是累进税**（`TC-ECO-36`）：当前按净资产 × 1.2% 单一税率，文档要求按持有套数累进。
- **清算拍卖不足以清偿**（`TC-BANK-14`）：地块按 `value×(1+12%×lv)` 计入净资产，拍卖只给 85%、抵押只给 70%，「拍卖后债务清零」的分支实际不可达，清算必然走向出局。
- 章节切换会清空政策条标签（热度影响仍在）。
- 道具让「会玩的人」优势变大：人类可以精确用遥控骰子躲雷，AI 的启发式判据还不够精细。
- 没有音效，美术仍是几何占位。
