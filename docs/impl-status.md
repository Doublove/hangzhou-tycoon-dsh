## 三、已知偏差（6 项，V1.6 之后仍存在）

| # | 偏差 | 文档要求 | 当前实现 | 影响 | 归属 |
|---|---|---|---|---|---|
| 1 | 过路费上限 | 25% | 30% | 与 8.3 红线不同数 | Phase 0 |
| 2 | 升级 ROI | 30% / 30% | 60% / 12% | 升级是负期望，六级建筑永不可见 | Phase 0 |
| 3 | 租金率 | 每级 +0.5% | 每级 +0.3% | 升级收益更弱 | Phase 0 |
| 4 | 空置率 | 100/50/25% | 无 | 租金零风险，破产率过低 | Phase 0 |
| 5 | 贷款利率 | 0.6%，仅温老板 −20% | 全员 ×0.8 = 0.48% | 借钱的成本被系统性低估，温老板被动失效 | Phase 0 |
| 6 | 税务 | 持有 ≥4 套起累进 | 净资产 × 1.2% 单一税率 | 抑制囤地的意图未落地 | P2 |
| 7 | 破产接管 | 法拍池 3 回合竞拍 | 85% 直售 / 70% 抵押 | 价格由规则定，不由市场定 | P2 |
| 8 | 清算清偿 | 拍卖后债务可清零并复出 | `value×(1+12%×lv)` 计入净资产、拍卖只给 85%，清零分支不可达 | 清算必然走向出局 | Phase 0（随偏差 2 一并修） |
| 9 | 热度自然回归 | 每月回归 3% | 未实现 | 热度只能单向被事件推动，板块轮动体感弱 | P2 |
| 10 | 政策条 | 显示全部生效项 | 切章后 `mods` 清空，标签丢失（热度影响仍在） | 玩家看不到在生效什么 | Phase 0（小） |
